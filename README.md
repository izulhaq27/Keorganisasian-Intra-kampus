# Website Landing Page BEM UNUGIRI

Repositori ini berisi kode sumber untuk website *landing page* resmi **Badan Eksekutif Mahasiswa (BEM) Universitas Nahdlatul Ulama Sunan Giri (UNUGIRI)**. Website ini dirancang dengan gaya modern, responsif, dan dinamis, mencerminkan semangat dan inovasi mahasiswa.

## Fitur Utama

- **Desain Modern & Profesional:** Menggunakan palet warna biru dan kuning (aksen) dengan elemen *Glassmorphism*.
- **Responsif (Mobile-First):** Tampilan dioptimalkan untuk berjalan dengan sempurna di berbagai ukuran layar (HP, tablet, hingga desktop).
- **Smooth Navigation:** Navigasi dengan efek transisi gulir (scroll) yang halus.
- **Scroll Reveal Animation:** Elemen halaman muncul secara perlahan dan elegan saat pengguna menggulir ke bawah.
- **Struktur Modular:** Kode telah dibagi ke dalam file `index.html` (struktur), `style.css` (gaya kustomisasi), dan `script.js` (logika interaktif).

## Teknologi yang Digunakan

Website ini dibangun murni menggunakan pendekatan front-end tanpa proses instalasi yang rumit, sehingga siap untuk langsung di-*deploy* ke hosting statis seperti GitHub Pages.

1. **HTML5 Semantik:** Struktur halaman yang jelas untuk SEO dan aksesibilitas.
2. **Tailwind CSS (via CDN):** Framework utilitas CSS terkemuka untuk gaya yang efisien tanpa perlu setup *build-tools*.
3. **Vanilla JavaScript:** Logika interaktivitas yang ringan tanpa membebani website dengan library eksternal berukuran besar.
4. **Google Fonts:** Menggunakan *Poppins* untuk heading dan *Inter* untuk body teks.

## Cara Menjalankan Secara Lokal

Anda tidak perlu menginstal Node.js atau *tools* kompilasi tambahan:

1. **Download atau Clone** repositori ini ke komputer Anda.
2. **Buka file `index.html`** langsung di browser (klik ganda pada file tersebut), ATAU
3. **Gunakan Local Server** (seperti ekstensi *Live Server* di VS Code, atau Laragon/XAMPP) untuk pengalaman *hot-reload* yang lebih baik.

## Deployment

Proyek ini sangat ideal untuk dipublikasikan langsung menggunakan **GitHub Pages**, **Vercel**, atau **Netlify**. Cukup hubungkan repositori Anda ke platform tersebut dan arahkan root folder ke lokasi saat ini.
